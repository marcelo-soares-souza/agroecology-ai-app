# Agroecology Map AI — Mobile

Flutter app for Android and iOS. It provides authenticated access to the
Agroecology Map AI knowledge base, local chat history, community profiles,
document browsing, document suggestions, profile management, and account flows.

Current app version: `1.2.0+15`.

## Stack

- **Flutter 3.44.x** + **Dart 3.12**
- **Riverpod** for state management
- **GoRouter** for declarative navigation and auth redirects
- **Dio** for HTTP, token refresh, and API interceptors
- **flutter_secure_storage** for access/refresh token storage
- **shared_preferences** for local chat history settings/cache
- **flutter_markdown** for formatted AI answers
- **flutter_pdfview** for document PDF viewing
- **image_picker**, **file_picker**, and **url_launcher** for mobile workflows
- **flutter_localizations** with generated ARB translations

## Setup

```bash
cd app
flutter pub get
```

## Run

Production API:

```bash
flutter run --dart-define=API_BASE_URL=https://ai.agroecologymap.org
```

Local backend from desktop/iOS simulator:

```bash
flutter run --dart-define=API_BASE_URL=http://localhost:8000
```

Local backend from Android emulator:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

## Build

```bash
flutter build apk --release --dart-define=API_BASE_URL=https://ai.agroecologymap.org
flutter build appbundle --release --dart-define=API_BASE_URL=https://ai.agroecologymap.org
flutter build ipa --no-codesign --dart-define=API_BASE_URL=https://ai.agroecologymap.org
```

## Routes

| Route | Screen |
| ----- | ------ |
| `/` | Landing page; redirects authenticated users to chat |
| `/chat` | Authenticated RAG chat |
| `/login`, `/register` | Authentication |
| `/forgot-password`, `/reset-password` | Password recovery |
| `/confirm-email`, `/resend-confirmation` | Email confirmation |
| `/confirm-delete-account` | Account deletion confirmation |
| `/community`, `/community/:slug` | Community directory and public profile |
| `/profile`, `/profile/edit`, `/profile/:slug` | Own profile, editor, and public profile |
| `/documents`, `/documents/:id`, `/documents/:id/view` | Document browser and PDF viewer |
| `/suggestions`, `/suggestions/new`, `/suggestions/:id`, `/suggestions/:id/edit` | Authenticated document suggestions |
| `/about`, `/privacy`, `/terms` | Static project/legal pages |

## Architecture

Clean Architecture by feature (`domain` -> `data` -> `presentation`):

```
app/lib/
├── bootstrap/          App bootstrap and provider setup
├── core/
│   ├── config/         Runtime API configuration
│   ├── http/           Dio client, interceptors, API errors
│   ├── navigation/     GoRouter setup and auth redirects
│   ├── storage/        Secure token and local preference storage
│   ├── theme/          App theme
│   └── ui/             Shared widgets
├── features/
│   ├── auth/           Login, register, token refresh, account deletion
│   ├── chat/           Ask flow, answer polling, local history
│   ├── community/      Public user directory/profile
│   ├── documents/      Document list/detail/PDF view
│   ├── profile/        Own profile and avatar updates
│   └── suggestions/    User document suggestions
└── l10n/               ARB translations and generated localizations
```

## Localization

Translations live in `lib/l10n/*.arb` and are generated by Flutter from
`l10n.yaml`. Supported locales are English, Portuguese, Spanish, and French.

```bash
flutter gen-l10n
```
